# ВыборВкуса для Android

Отдельное приложение на Kotlin и Jetpack Compose. С iOS-версией его объединяют:

- **сервер** (`backend/`) — цены Ленты, Магнита, Ашана, ВкусВилла и Купера, аккаунты, слежение за ценой;
- **каталог** — тот же `RecipeApp/Resources/seed.json` и иллюстрации `Food/*.png` (сборка берёт их оттуда, копий нет);
- **правила расчётов** — порции, КБЖУ, фильтры, список покупок, сравнение корзин. Тесты в `core` повторяют
  тестовые случаи iOS, поэтому обе версии считают одинаково.

## Как поставить на телефон

1. Откройте на телефоне https://github.com/GaryBail/recipe-app/releases/tag/android и скачайте `VyborVkusa.apk`.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите.
3. Новые сборки ставятся поверх старых, данные сохраняются.

Нужен Android 8.0 или новее.

## Устройство

```
core/   — чистый Kotlin без Android: модели, каталог, расчёты, клиент сервера, тесты.
          Позже его можно сделать общим с iOS (Kotlin Multiplatform) без переписывания.
app/    — экраны на Compose, хранение данных пользователя (JSON-файл), навигация.
  src/androidTest/ScreenshotTest.kt — проход по экранам на эмуляторе со скриншотами.
```

Сборка и проверки — в GitHub Actions (`.github/workflows/android.yml`): тесты `core`, сборка APK,
публикация в релиз `android`, затем проход по экранам на эмуляторе Android 14; скриншоты попадают
в ветку `android-screenshots`.

Собрать самому (Windows, macOS, Linux): установите Android Studio, откройте папку `android/` и нажмите Run.
Или в терминале: `./gradlew :app:assembleDebug` (на Windows — `gradlew.bat`).

## Сервер

Адрес сервера задаётся в профиле приложения (тестовые сборки) или при сборке:
`./gradlew :app:assembleRelease -PvvServerUrl=https://api.example.ru -PvvAllowServerOverride=false`.
Без сервера показываются тестовые цены.

## Что есть в первой версии

Каталог с поиском, подборками, кухнями, рубриками и фильтрами (в т. ч. «Мне подходит» по аллергиям);
рецепт с порциями, КБЖУ и % дневной нормы; выбор продуктов и сборки; сравнение корзины по магазинам
(Санкт-Петербург по умолчанию) и передача корзины во ВкусВилл; список покупок с режимом «В магазине»;
избранное; «Из того, что есть»; режим готовки с таймерами; вход по почте; слежение за ценой сборки.
