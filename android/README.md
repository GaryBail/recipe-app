# ВыборВкуса для Android

Отдельное приложение на Kotlin и Jetpack Compose. С iOS-версией его объединяют:

- **сервер** (`backend/`) — цены Ленты, Магнита, Ашана, ВкусВилла и Купера, аккаунты, слежение за ценой;
- **каталог** — тот же `RecipeApp/Resources/seed.json` и иллюстрации `Food/*.png` (сборка берёт их оттуда, копий нет);
- **правила расчётов** — порции, КБЖУ, фильтры, список покупок, сравнение корзин. Тесты в `core` повторяют
  тестовые случаи iOS, поэтому обе версии считают одинаково.

## Как поставить на телефон

1. Откройте на телефоне https://github.com/GaryBail/recipe-app/releases/tag/android и скачайте `VyborVkusa.apk`.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите.
3. Новые сборки ставятся поверх старых, данные сохраняются.

Нужен Android 8.0 или новее.

## Устройство

```
core/   — чистый Kotlin без Android: модели, каталог, расчёты, клиент сервера, тесты.
          Позже его можно сделать общим с iOS (Kotlin Multiplatform) без переписывания.
app/    — экраны на Compose, хранение данных пользователя (JSON-файл), навигация.
  src/androidTest/ScreenshotTest.kt — проход по экранам на эмуляторе со скриншотами.
```

Сборка и проверки — в GitHub Actions (`.github/workflows/android.yml`): тесты `core`, сборка APK,
публикация в релиз `android`, затем проход по экранам на эмуляторе Android 14; скриншоты попадают
в ветку `android-screenshots`.

Собрать самому (Windows, macOS, Linux): установите Android Studio, откройте папку `android/` и нажмите Run.
Или в терминале: `./gradlew :app:assembleDebug` (на Windows — `gradlew.bat`).

## Сервер

Адрес сервера задаётся в профиле приложения (тестовые сборки) или при сборке:
`./gradlew :app:assembleRelease -PvvServerUrl=https://api.example.ru -PvvAllowServerOverride=false`.
Без сервера показываются тестовые цены.

## Что есть

Каталог с поиском, подборками, кухнями, рубриками и фильтрами (в т. ч. «Мне подходит» по аллергиям);
рецепт с порциями, КБЖУ и % дневной нормы; выбор продуктов («чаще выбирают» — по данным сообщества) и сборки;
сравнение корзины по магазинам (Санкт-Петербург по умолчанию) и передача корзины во ВкусВилл; список покупок
с режимом «В магазине»; избранное; «Из того, что есть»; режим готовки с таймерами; свои рецепты с фото шагов;
сообщество (лента сборок и рецептов, оценки и отзывы, сохранение себе, публикация, жалобы, скрытие авторов);
вход по почте, через VK ID и Яндекс ID; слежение за ценой сборки; уведомления.

**Уведомления** приходят без Firebase: приложение раз в полчаса (при наличии сети) спрашивает сервер о новых
оценках и снижении цен и показывает системное уведомление. Так работает на любых телефонах, в том числе без
сервисов Google. Мгновенные push через Firebase / RuStore Push можно добавить позже — нужны ключи проектов.

**VK ID и Яндекс ID** включаются на сервере (переменные в `deploy/.env.example`); кнопки входа появляются
в приложении сами, когда сервер их поддерживает.

## Ключ подписи для RuStore

RuStore принимает только приложения, подписанные **вашим** ключом, и все обновления должны быть подписаны
**тем же** ключом. Потеряете ключ — придётся через поддержку RuStore заново публиковать приложение,
а пользователям — переустанавливать его. Поэтому ключ создаёте вы, хранится он у вас (и копия — в надёжном месте),
а в GitHub попадает только в зашифрованные секреты.

1. Создайте ключ (Windows, PowerShell; `keytool` входит в Android Studio):
   ```
   & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore vyborvkusa-release.jks -alias vyborvkusa -keyalg RSA -keysize 4096 -validity 10000
   ```
   Придумайте пароль (сохраните в менеджере паролей), имя и организацию можно указать как есть.
2. Сохраните файл `vyborvkusa-release.jks` и пароль в двух местах (например, менеджер паролей + флешка).
3. Превратите файл в текст для GitHub: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("vyborvkusa-release.jks")) | Set-Clipboard`
4. На GitHub: репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `RUSTORE_KEYSTORE_BASE64` — вставьте из буфера;
   - `RUSTORE_KEYSTORE_PASSWORD` и `RUSTORE_KEY_PASSWORD` — пароль;
   - `RUSTORE_KEY_ALIAS` — `vyborvkusa`.
5. Actions → Android → Run workflow → отметьте «release», укажите адрес сервера → Run. Готовые
   `VyborVkusa-rustore.aab` и `.apk` будут в артефакте `rustore-release` этого запуска.

В консоли RuStore при первой загрузке AAB попросят ключ подписи в виде архива PEPK (утилита `pepk.jar`
и ключ шифрования — в консоли) и сертификат загрузки. Можно загружать и подписанный APK — тогда это не нужно.

С 2027 года Google требует регистрировать разработчика и имя пакета (`com.garybail.vyborvkusa`) даже для
приложений вне Google Play, в том числе в России. Понадобится SHA-256 отпечаток этого же ключа:
`keytool -list -v -keystore vyborvkusa-release.jks -alias vyborvkusa`.
