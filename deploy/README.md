# Размещение сервера

Пошагово, с компьютера на Windows. Займёт около часа, из них большая часть — ожидание.

## Что понадобится

| Что | Зачем | Примерная цена |
|---|---|---|
| **Сервер (VPS) в Москве или Петербурге**: 2 ядра, 4 ГБ памяти, 40+ ГБ диска, Ubuntu 24.04 | Работает круглосуточно: API, сообщество, проверка цен | 830–1 200 ₽/мес у недорогих провайдеров (октябрь 2026) |
| **Домен** (например, `рецепты-api.ru` или поддомен своего сайта) | iPhone подключается только по HTTPS, а сертификат выдают на домен | зависит от регистратора, сравните перед покупкой |
| Почта с паролем приложения (Яндекс, Mail.ru) — по желанию | Отправка кодов подтверждения и восстановления пароля | бесплатно |

**Почему российский сервер:** сайты Пятёрочки и Перекрёстка не открылись с зарубежного сервера GitHub
(проверено при сборке — страница не загрузилась за 20 секунд). С российского IP шансов больше, но гарантии
нет: проверьте сразу после установки (шаг 5).

**Память:** браузер для сайтов магазинов занимает 1–1,5 ГБ. С 2 ГБ сервер будет работать на пределе — берите 4 ГБ.

Где смотреть: [servercalc.ru](https://servercalc.ru/vps/rossiya/) сравнивает тарифы. Например, на 25.10.2026 там были
AdminVPS Micro (899 ₽), FirstVDS «Разгон SSD» (919 ₽), VDSina 2×4 ГБ (1 200 ₽); у HostKey vm.v2-nano — 830 ₽
(у HostKey есть дата-центры в Москве — уточните при заказе). Перед оплатой проверьте цену и что сервер находится в России.

## 1. Арендуйте сервер

При заказе выберите **Ubuntu 24.04** и запишите **IP-адрес** и **пароль root** (обычно приходят на почту).

## 2. Направьте домен на сервер

В панели регистратора домена создайте **A-запись**: имя `api` (или `@` для самого домена) → IP сервера.
Получится, например, `api.ваш-домен.ru`. Обновление занимает от нескольких минут до часа.

Проверить в PowerShell: `nslookup api.ваш-домен.ru` — должен показать IP сервера.

## 3. Подключитесь к серверу

Откройте **PowerShell** (Пуск → PowerShell) и введите:

```
ssh root@IP_СЕРВЕРА
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем вставьте пароль
(при вводе он не отображается — это нормально; вставить можно правым кликом).

## 4. Установите одной командой

```
curl -fsSL https://raw.githubusercontent.com/GaryBail/recipe-app/main/deploy/setup.sh | bash -s -- api.ваш-домен.ru
```

Скрипт обновит систему, включит файрвол (открыты только SSH, 80 и 443) и автоматические обновления
безопасности, поставит Docker, скачает код, соберёт и запустит сервер с HTTPS, настроит ежедневную копию базы.
Первый запуск — 5–10 минут.

В конце появится адрес. Откройте в браузере `https://api.ваш-домен.ru/health` — должно быть `{"ok":true}`.

## 5. Проверьте, открываются ли магазины

Откройте в браузере (первый запрос идёт до минуты — запускается браузер на сервере):

```
https://api.ваш-домен.ru/search?store=pyaterochka&city=msk&q=молоко
https://api.ваш-домен.ru/search?store=perekrestok&city=msk&q=молоко
```

- Список товаров с ценами — всё работает.
- `Магазин сейчас не отвечает` — сайт не пустил сервер. Пришлите мне вывод команды
  `cd /opt/recipe-app/deploy && docker compose logs api --tail 80` — разберёмся.

## 6. Укажите адрес в приложении

⚙️ → **Сервер** → `https://api.ваш-домен.ru` → «Проверить соединение».

## Почта и push

Откройте настройки на сервере: `nano /opt/recipe-app/deploy/.env`, раскомментируйте (уберите `#`) и заполните
строки `SMTP_…` (и `APNS_…`, если есть аккаунт Apple Developer; файл ключа `.p8` положите в
`/opt/recipe-app/deploy/secrets/`). Сохранить — `Ctrl+O`, `Enter`, выйти — `Ctrl+X`. Затем:

```
cd /opt/recipe-app/deploy && docker compose up -d
```

Пока почта не настроена, коды подтверждения можно посмотреть в логе:
`docker compose logs api | grep "код"`.

## Обслуживание

Все команды — из папки `/opt/recipe-app/deploy`.

| Задача | Команда |
|---|---|
| Обновить до последней версии из GitHub | `./update.sh` (сначала делает копию базы) |
| Посмотреть логи | `docker compose logs api --tail 100` |
| Перезапустить | `docker compose restart api` |
| Сделать копию базы сейчас | `./backup.sh` |
| Проверить цены вручную | `docker compose exec api python -m app.price_watch` |

**Резервные копии** базы делаются каждый день в 03:30 в `data/backups/`, хранятся последние 14.
Они лежат на том же сервере — раз в неделю-месяц скачивайте свежую к себе (в PowerShell):

```
scp root@IP_СЕРВЕРА:/opt/recipe-app/deploy/data/backups/*.gz .
```

**Восстановление из копии:**

```
cd /opt/recipe-app/deploy
docker compose stop api
gunzip -c data/backups/community-ДАТА.db.gz > data/community.db
docker compose start api
```

## Безопасность

- Вход по паролю root — самое слабое место. Лучше настроить вход по SSH-ключу и отключить пароль
  (могу расписать по шагам).
- Файл `.env` с паролями доступен только root и не попадает в GitHub.
- Репозиторий публичный: код виден всем, но ключей и паролей в нём нет. Если хотите закрыть код —
  сделайте репозиторий приватным, тогда скрипту установки понадобится токен доступа.
