# recipe-app

iOS-приложение с рецептами: пользователь выбирает рецепт, подбирает конкретные продукты под каждый ингредиент, сохраняет «сборку» и находит магазин с доставкой, где вся корзина обойдётся дешевле.

## Что уже есть

- **Каталог** — рецепты, ингредиенты-категории («Твёрдый сыр») и конкретные продукты («Пармезан»). Стартовые данные: `RecipeApp/Resources/seed.json`.
- **Сборки** — выбор продукта для каждого ингредиента и сохранение (SwiftData). Сборку можно изменить или сохранить как новый вариант; можно добавить свой продукт, которого нет в каталоге.
- **Свои рецепты** — «+» на главном экране: рецепт сразу с набором продуктов (первая сборка).
- **Сообщество** — публикация сборки (вместе с рецептом), оценки и отзывы, «Рекомендуем» для лучшей сборки, сохранение чужой сборки себе, жалобы и скрытие авторов.
- **Аккаунты** — вход через Apple или регистрация по email и паролю; профиль, выход, удаление аккаунта.
- **Уведомления** — об оценках и отзывах на ваши сборки: колокольчик в приложении и push на iPhone.
- **Сравнение корзины** — `PriceProvider` (интерфейс источника цен), `CartComparator` (упаковки, доставка, минимальный заказ, ранжирование). Сейчас подключён `MockPriceProvider` с вымышленными магазинами и ценами.
- **Сервер цен** (`backend/`) — ищет товары и цены в Перекрёстке и Пятёрочке и подбирает товар под каждую позицию сборки. Адрес сервера задаётся в приложении: ⚙️ → «Сервер цен»; если пусто — тестовые данные. Подробнее: [backend/README.md](backend/README.md).
- **Переход в магазин** — проверка, установлено ли приложение магазина; если нет — App Store или сайт. Если магазин не принимает корзину по ссылке, список покупок копируется в буфер.

## Структура

```
project.yml              — конфиг XcodeGen (из него генерируется .xcodeproj)
RecipeApp/
  App/                   — точка входа
  Models/                — модели SwiftData
  Data/                  — загрузка стартовых данных
  Services/              — цены, сравнение корзин, переход в магазин
  Views/                 — экраны SwiftUI
  Resources/seed.json    — стартовые рецепты и продукты
RecipeAppTests/          — unit-тесты
backend/                 — сервер: цены и сообщество (Python, FastAPI, SQLite)
.github/workflows/ios.yml — сборка и тесты на macOS в GitHub Actions
```

## Как собрать

Файл `.xcodeproj` в репозитории не хранится — он генерируется:

```bash
brew install xcodegen
xcodegen generate
open RecipeApp.xcodeproj
```

Нужен Mac с Xcode 16+. Без своего Mac код проверяется автоматически: при каждом push GitHub Actions собирает приложение и прогоняет тесты (вкладка **Actions** в репозитории).
