# Сервер приложения

Части: **цены в магазинах**, **аккаунты**, **сообщество** (публикация сборок, оценки, рекомендации) и **уведомления**.

## Цены

Ищет товары и цены в магазинах и отдаёт их iOS-приложению. Сейчас подключены **Перекрёсток** и **Пятёрочка**
через неофициальные библиотеки [perekrestok_api](https://github.com/Open-Inflation/perekrestok_api)
и [pyaterochka_api](https://github.com/Open-Inflation/pyaterochka_api) (MIT). Библиотеки открывают сайт
магазина в скрытом браузере (Camoufox) и делают те же запросы, что и обычный посетитель.

> ⚠️ Это прототип. Неофициальный доступ может перестать работать при изменениях на сайтах,
> а автоматический сбор данных может противоречить пользовательским соглашениям магазинов.
> Перед коммерческим запуском — проверить соглашения и согласовать доступ с сетями.

## Что делает

- `GET /cities` — список городов.
- `GET /stores?city=msk` — магазины с доставкой в город.
- `GET /search?store=perekrestok&city=msk&q=пармезан` — поиск товаров с ценами и фасовкой.
- `POST /offers` — подбор товара под каждую позицию сборки: берёт первые результаты поиска магазина,
  оставляет самые подходящие по названию и выбирает самый дешёвый под нужное количество
  (штучные — целыми упаковками, весовые — по весу). Возвращает ещё до 3 альтернатив.

Результаты поиска кэшируются на 3 часа, чтобы не нагружать сайты.

## Сообщество

Хранится в SQLite (`community.db` рядом с сервером, путь меняется переменной `COMMUNITY_DB`).

- `POST /community/builds` — опубликовать сборку вместе с рецептом (так можно делиться и своими рецептами).
- `GET /community/builds?recipe_id=…&sort=top|new&mine=true` — сборки; `top` — по рейтингу.
- `GET /community/builds/{id}`, `DELETE /community/builds/{id}` (только автор).
- `PUT /community/builds/{id}/rating` — оценка 1–5 и комментарий; повторная заменяет прежнюю, свою сборку оценить нельзя.
- `GET /community/builds/{id}/ratings` — отзывы.
- `POST /community/builds/{id}/report` — жалоба; после 3 жалоб от разных людей сборка скрывается.
- `POST /community/blocks` — скрыть все сборки и отзывы автора (требование App Store для пользовательского контента).

**Рекомендации.** Сортировка `top` использует байесовское сглаживание: рейтинг стягивается к 3.5 с весом
трёх оценок, поэтому сборка с одной пятёркой не обгоняет сборку с сотней оценок 4.8. Лучшая сборка
показывается в приложении с пометкой «Рекомендуем».

Читать сборки можно без входа; публиковать, оценивать, жаловаться — только с аккаунтом.

## Аккаунты

- `POST /auth/register` — email, пароль (от 8 символов, буквы и цифры), имя, город.
- `POST /auth/login` — email и пароль.
- `POST /auth/apple` — вход через Apple: сервер проверяет подпись identity token по ключам Apple,
  издателя, срок и bundle id (`APPLE_BUNDLE_ID`, по умолчанию `com.garybail.recipeapp`).
- `GET/PATCH /auth/me` — профиль; при смене имени обновляется подпись под сборками и отзывами.
- `POST /auth/logout`, `DELETE /auth/me` — выход и удаление аккаунта со всем контентом (требование App Store).

Пароли хранятся как scrypt-хэш с солью, в базе лежит только SHA-256 от токена сессии.
Вход через Apple не привязывается автоматически к аккаунту с тем же email: email при регистрации
не подтверждается, и иначе чужой аккаунт можно было бы «занять» заранее.

Не сделано: подтверждение email, восстановление пароля, ограничение числа попыток входа.

## Уведомления

Когда сборку оценивают или комментируют, автор получает уведомление:
- всегда — в списке в приложении (`GET /notifications`, `POST /notifications/read`);
- push на iPhone — если на сервере настроены ключи APNs.

Для push нужен платный Apple Developer аккаунт: в нём создаётся ключ APNs (.p8). Переменные окружения:

```
APNS_KEY_PATH=/путь/к/AuthKey_XXXX.p8
APNS_KEY_ID=XXXX          # id ключа
APNS_TEAM_ID=YYYY         # Team ID аккаунта разработчика
APNS_SANDBOX=1            # 1 — для сборок из Xcode, 0 — для TestFlight/App Store
```

Без них сервер работает, просто не отправляет push.

## Запуск (Windows / macOS / Linux)

Нужен Python 3.10+.

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m camoufox fetch          # скачает браузер (один раз)
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Проверка: откройте http://localhost:8000/docs — там можно вызвать любой метод.
Первый запрос к магазину идёт дольше (запускается браузер), дальше быстрее.

`HEADLESS=0` перед запуском покажет окно браузера — удобно, если магазин просит капчу.

В приложении: ⚙️ → «Сервер цен» → адрес компьютера в локальной сети, например `http://192.168.1.10:8000`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят на сайты: парсеры проверяются на сохранённых ответах (`tests/fixtures`).

## Как добавить магазин

Написать адаптер в `app/stores/` по образцу существующих (`delivers_to`, `search`, `close`)
и добавить его в `default_adapters()` в `app/main.py`.

## Что пока не сделано

- Условия доставки (стоимость, минимальный заказ) — не получаем, в приложении пометка «уточняется».
- Подбор товара по названию грубый: при ошибке подбора стоит смотреть альтернативы.
- Сервер нужно где-то разместить, чтобы приложение работало не только в домашней сети.
